# fuel-calculator

汽油百分比计算工具，用于计算加油金额、百分比与升数之间的转换，适配昂科威Plus 2024 68L 油箱，支持显示长沙 95# 汽油价格及调价日历。

## 功能特性

- **双模式切换**：输入金额计算百分比 / 输入百分比计算金额
- **实时油价**：显示今日 95# 汽油价格及涨跌幅，并展示下轮预测价格
- **自定义油箱容量**：可修改油箱大小（默认 68L）
- **快速输入**：支持 230 元、360 元、40%、60% 快捷按钮
- **调价日历**：可视化查看调价日期，支持日期选择

## 使用说明

1. 打开页面后，可调整右上角油箱容量（单位：L）
2. 选择模式：
   - **输入金额 → 算百分比**：输入加油金额，自动计算对应升数和占油箱百分比
   - **输入百分比 → 算金额**：输入占油箱百分比，自动计算所需金额和升数
3. 输入油价（或点击"当前油价"自动填充）
4. 页面实时显示加油升数、百分比、金额，超过油箱容量时高亮提醒

- 油价预测：[v1.apizero.cn](https://v1.apizero.cn/api/oil-price-forecast)
