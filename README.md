# fuel-calculator

汽油百分比计算工具，用于计算加油金额、百分比与升数之间的转换，适配昂科威Plus 2024 68L 油箱，支持显示长沙 95# 汽油价格、下轮预测及调价日历。

## 功能特性

- **双模式切换**：输入金额计算百分比 / 输入百分比计算金额
- **实时油价**：自动获取今日 95# 汽油价格及涨跌幅
- **下轮预测**：自动获取下轮调价窗口日期和预测涨跌幅度
- **调价日历**：自动获取全年调价窗口，可视化查看并选择日期
- **自定义油箱容量**：可修改油箱大小（默认 68L）
- **快速输入**：支持 230 元、360 元、40%、60% 快捷按钮
- **加载状态**：页面加载时显示 shimmer 动画，数据到达后自动更新

## 使用说明

1. 打开页面后，自动获取今日油价和下轮预测
2. 可调整右上角油箱容量（单位：L）
3. 选择模式：
   - **输入金额 → 算百分比**：输入加油金额，自动计算对应升数和占油箱百分比
   - **输入百分比 → 算金额**：输入占油箱百分比，自动计算所需金额和升数
4. 页面实时显示加油升数、百分比、金额，超过油箱容量时高亮提醒
5. 点击日历图标打开调价日历，选择日期后自动填充到日期选择器

## 技术栈

- 纯静态 HTML / CSS / JavaScript，无需后端
- 响应式设计，支持移动端
- 油价数据通过公开 API 自动获取，无需手动维护
- 请求失败时自动指数退避重试（最多 3 次）

## 数据来源

- 今日油价：`v2.xxapi.cn/api/oilPrice`
- 下轮预测：`v1.apizero.cn/api/oil-price-forecast?action=forecast`
- 调价日历：`v1.apizero.cn/api/oil-price-forecast?action=schedule`

## 版本管理

- 版本号格式：`1.yy.mmdd`，其中 `yy` 为年份后两位，`mmdd` 为当前月日
- 示例：`1.26.0914`（2026年9月14日）
- 运行 `update-version.bat` 自动更新 `VERSION` 文件

## API 限流处理

- 所有请求设置 `cache: 'no-store'`，确保每次加载获取最新数据
- 遇到 HTTP 429 或 body 中 code 4029 时自动重试，指数退避（1s → 2s → 4s）
- 网络断开时同样自动重试，最多 3 次
- 重试耗尽后静默降级，不影响页面其他功能
